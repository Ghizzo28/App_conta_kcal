# App Conta Kcal

Prototype SwiftUI per un'app iOS che consente di:

- Tenere traccia delle calorie giornaliere e dei macro-nutrienti.
- Impostare obiettivi personalizzati (calorie e macro).
- Creare e gestire i pasti liberamente nel diario.
- Inserire alimenti rapidamente con macro personalizzate.
- Simulare la scansione del codice a barre e calcolare i valori in base al peso.
- Creare una libreria personale di ricette e piatti composti.

## Struttura

- `AppContaKcalApp.swift`: entry point SwiftUI.
- `Models/`: modelli dati (macro, pasti, ricette).
- `Views/`: viste del diario, inserimento rapido, libreria e impostazioni.

## Note

Questo repository contiene i file SwiftUI essenziali per avviare un progetto iOS in Xcode.
